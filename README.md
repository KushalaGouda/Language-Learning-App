# 🌎 LinguaLearn

LinguaLearn is an interactive language-learning web app for learning vocabulary, practicing flashcards, taking quizzes, and tracking progress.

## ✨ Features

* 📚 Daily language lessons
* 🃏 Interactive flashcards
* 📝 Practice quizzes
* 📊 Learning progress tracking
* 🔐 Firebase authentication
* ☁️ Firebase Firestore data storage
* 🌍 English, Kannada & Hindi support

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
* Firebase
* Git & GitHub
